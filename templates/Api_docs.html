Documentation API

Tous les endpoints nécessitent d'être authentifié, de deux façons possibles : soit via le cookie de session du navigateur (connecté normalement sur le site), soit via une clé API personnelle envoyée dans l'en-tête X-API-Key (génère la tienne depuis Paramètres → Clé API). La deuxième méthode permet d'appeler l'API depuis un script ou un outil comme curl/Postman, sans navigateur.
